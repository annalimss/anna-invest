# anna-invest
# 📊 Ferramenta de Cálculo de Investimentos

Este projeto consiste em uma planilha interativa desenvolvida para auxílio no planejamento de investimentos, projeção de patrimônio e cálculo de dividendos mensais.

## 🛠️ Funcionalidades

* **Configurações Pessoais:** Definição de salário e sugestão automática de valor para investimento.
* **Projeção de Longo Prazo:** Cálculo de patrimônio acumulado e dividendos com base na taxa de rendimento mensal.
* **Análise de Cenários:** Comparativo de rendimentos para diferentes horizontes de tempo (ex: 2 e 5 anos).
* **Alocação por Perfil:** Distribuição percentual por tipo de fundo (Papel, Tijolo, Híbridos, FOFs, etc.).

## 📁 Arquivos do Repositório

* `INV.xlsx`: Planilha principal com os cenários e simulações.
